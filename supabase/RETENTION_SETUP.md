# Квартальное хранение результатов

Для включения уведомлений и автоматического удаления:

1. Примените `schema.sql` к проекту Supabase.
2. Разверните Edge Function `quarterly-retention`.
3. Добавьте секреты функции:
   - `RESEND_API_KEY` — API-ключ Resend;
   - `RETENTION_FROM_EMAIL` — подтверждённый адрес отправителя;
   - `RETENTION_CRON_SECRET` — длинная случайная строка.
4. В Supabase Vault сохраните `project_url` и тот же `retention_cron_secret`, как показано в `retention-cron.sql`.
5. Выполните `retention-cron.sql` в SQL Editor Supabase.

Задание запускается ежедневно в 06:00 UTC (09:00 МСК). Письма отправляются всем активным администраторам за 14, 3, 2 и 1 день. В первые три дня нового квартала процедура удаляет все записи прошлых кварталов и соответствующие файлы; трёхдневное окно позволяет повторить очистку после временного сбоя.
